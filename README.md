# 🎮インディーズゲーム企画書  
## 『唐山の木:記憶との和解』  
### *Korean Traditional Occult: Reconciliation with Memories*

---

## 📖 概要  

本作品は**韓国の田舎町**を背景にした**短編インタラクティブストーリーゲーム**です。  

物語は次の 2 つの視点で展開されます:  
- **夏**:おばあさんが亡くなった日を回想する*弟の話*  
- **冬**:長い不和の末に故郷を訪れた**お姉さんの話*

奇怪な体験をしながらも家族に打ち明けることができなかった弟、  
そして、そんな妹を理解しようとする平凡なお姉さん。

>夢と現実、見えるものと見えないもの、  
>家族間の切なさと断絶を扱った感性的な話です。

## 🧩 主な特徴

- 🌳 **韓国伝統オカルト素材**  
  （堂山の木、覆盆子庁、雀舌茶など郷土的要素を活用）

- ❄️ **季節区分型 2部構成**  
  （夏=妹/冬=姉）

- 🧠 **心理的ファンタジーと家族ドラマの融合**

- 👁️**「見えるもの」と「見えないもの」の境界に対する表現**

- ✍️ **短いが密度のある感情の流れと叙情的な演出**

## 💡 補足・今だからこその提案

- 本作で重要な役割を果たす「当山木（당산나무）」は、韓国の伝統的な信仰対象であり、近年では Netflix アニメ『デーモンハンターズ』にも登場するなど、グローバルな注目が高まっています。

- また、日本でも毎年夏には「オカルト・ホラー・郷愁系ストーリーゲーム」への関心が高まる傾向があり、本作はその季節的な雰囲気にも非常にマッチすると考えています。

→ つまり、「今」だからこそ届けたい物語です。
